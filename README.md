## 💡 How to Use

1. **Open** `logo-generator.html` in your browser
2. **Type** your brand name and optional tagline
3. **Pick** an icon from the 18 symbol library
4. **Choose** a font that matches your brand personality
5. **Select** a layout — Stacked, Inline, or Icon Only
6. **Apply** a color palette or set custom colors
7. **Set** the background color
8. **Adjust** icon size, font size, and letter spacing
9. **Preview** your logo live — including 3 mockup backgrounds
10. **Download** in PNG, JPG, or SVG format
